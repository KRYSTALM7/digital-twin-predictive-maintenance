# CNC Spindle Digital Twin – Predictive Maintenance

**Authors:** Sujan Kumar MV, Ganesh Khekare

This repository contains the implementation accompanying the research paper on simulation-driven predictive maintenance for CNC spindle systems using a digital twin, LSTM forecasting, autoencoder-based anomaly detection, and the SMART hybrid detection framework.

## Overview

The system uses a SimPy-based CNC spindle simulation to generate multivariate sensor time-series data and evaluate predictive-maintenance anomaly detection.

The pipeline consists of:

1. CNC spindle digital-twin simulation
2. Sensor-data preprocessing
3. LSTM-based forecasting
4. Autoencoder-based reconstruction
5. SMART hybrid anomaly detection
6. Multi-seed evaluation and statistical analysis
7. Maintenance feedback and detection-latency analysis

### Sensors

The simulation generates:

- Temperature
- Vibration
- Spindle motor current

### Simulated fault conditions

The simulation models physics-motivated fault conditions including:

- Bearing wear
- Cooling-system failure
- Mechanical imbalance

## Data Source

**No external industrial dataset is used for the reported experiments.**

The experimental sensor data are generated by the SimPy-based CNC digital-twin simulation included in this repository. The generated data are used as the input to the preprocessing, model-training, SMART detection, and evaluation pipeline.

The repository includes the generated raw simulation data under:

```text
data/raw/
```

The simulation can also be rerun to generate new datasets.

## Experimental Protocol

The experiments use independent random seeds to evaluate the stability of the proposed method.

For each seed:

1. Generate the CNC simulation data.
2. Preprocess the generated sensor data.
3. Split the data chronologically into training, validation, and test sets.
4. Train the LSTM forecasting model.
5. Train the autoencoder.
6. Calibrate detection thresholds using validation/training information as defined by the experimental protocol.
7. Run SMART on the held-out test data.
8. Compute precision, recall, F1-score, accuracy, and Mean Time to Detect (MTTD).

The paper reports results across **10 independent seeds (0–9)**.

## Models

### LSTM Forecaster

The LSTM model learns temporal patterns in the simulated sensor signals and uses forecasting error for anomaly detection.

### Autoencoder

The autoencoder learns representations of normal operating behaviour and uses reconstruction error to identify anomalous observations.

### SMART Hybrid Detector

SMART combines the signals produced by the forecasting and reconstruction models to make the final anomaly decision.

The framework also supports feature-specific detection for sensor signals such as temperature and vibration.

## Evaluation

The evaluation includes:

- Precision
- Recall
- F1-score
- Accuracy
- Mean Time to Detect (MTTD)
- Multi-seed performance
- 95% confidence intervals
- Paired statistical comparisons
- Ablation comparisons against component and baseline detectors

The reported experiments use a held-out test set for final evaluation.

## Paper Results

The paper reports the following multi-seed SMART result:

- **F1-score:** 0.526 ± 0.033

The paper also reports comparisons with the LSTM-only and Autoencoder-only component detectors and evaluates the method across ten independent seeds.

For the exact numerical results, tables, figures, and experimental definitions, please refer to the accompanying paper.

## Important Note on Reproduction

The repository contains simulation-generated data rather than measurements collected from a physical CNC machine. Therefore, the reported results should be interpreted as simulation-based experimental results.

Physical CNC/industrial validation is outside the scope of the current experimental setup and is identified as future work.
